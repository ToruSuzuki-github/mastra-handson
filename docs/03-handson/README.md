# 03. ハンズオン本体（Day 1 + Day 2 + Day 3 / 約20.5時間）

Mastra を「読んで分かる」から「書いて動かせる」に変えるための本編です。
**前提**: [01-setup/](../01-setup/) が完了していること。
[00-overview/](../00-overview/)（座学 67分）を先に読んでおくと、各手順の意味が繋がります。

---

## このハンズオンで作るもの

「**天気を調べて、旅行の持ち物を提案するエージェント**」を段階的に育てていきます。

1. まず素の Agent（Day1 Step2）
2. → 実際の天気 API を叩けるようにする（Step4）
3. → 会話を覚えるようにする（Day2 Step7）
4. → 「調査 → 提案 → 整形」の手順をワークフロー化し、分岐・ループ・人間の承認待ちまで組む（Step8）
5. → 持ち物提案を専門エージェントに任せる（Step9）
6. → 出力を採点し、プロンプトを直した前後を数字で比べる（Step11）
7. → **自作のフロントエンドから呼べるようにする**（Day3 Step13・14）

一貫したテーマで進むので、各機能が「何のために必要か」を追いやすい構成です。

---

## 3日の構成

| | 内容 | 時間 |
|---|---|---|
| [**day1/**](./day1/) 基礎編 | Agent / Tool / Studio / HTTP API という中核を一通り触る（Step 0〜6） | 6時間 |
| [**day2/**](./day2/) 応用編 | Memory / Workflow（分岐・ループ・承認待ち）/ マルチエージェント / 観測・評価（Step 7〜12） | 11.5時間 |
| [**day3/**](./day3/) フロントエンド編 | 型付きクライアント / Next.js 同居構成・チャット UI（Step 13〜14） | 3時間 |

2日連続で取るのが難しければ、基礎編を「Step 1〜3」「Step 4〜6」の2回（各3時間）に分割しても
成立します。応用編も同様です。

**Day 3 は独立性が高い**ので、Day1・Day2 から日を空けても、あるいは省いても本編は成立します。
ただし「Mastra が TypeScript であることの利点」を実感したいなら、ここを飛ばすと
その実物が手元に残りません（理由は [day3/README.md](./day3/README.md) 冒頭）。
