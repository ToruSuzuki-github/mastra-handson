# Step 6. 振り返りとメモ整理（30分）

学んだことを定着させるために、以下を書き留めておきます。

## 記録しておくもの

| 項目 | 内容 |
|---|---|
| スクリーンショット | Studio の対話画面、トレース画面（ツール呼び出しが見えるもの） |
| コード断片 | Agent 定義、Tool 定義（各20行程度） |
| つまずいた点 | エラーメッセージと解決法（[troubleshooting/](../../troubleshooting/) に追記） |
| 所感 | 他フレームワーク（LangChain 等）と比べてどうだったか |

## 振り返りの問い

- Agent と Tool の責務分担はどう設計すべきか
- `instructions` と `description` のどちらに何を書くべきか
- 自分の業務や身近な作業のどこに当てはめられそうか（3つ挙げてみる）
