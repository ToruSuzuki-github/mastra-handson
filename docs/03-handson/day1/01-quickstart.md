# Step 1. Quickstart：まず動くものを見る（45分）

## 1-1. プロジェクト生成（15分）

```bash
cd ~/work/mastra-handson    # コンテナ内のワークスペース直下
npm create mastra@latest quickstart-demo -- --llm openai
cd quickstart-demo
```

対話形式にしたい場合は `npm create mastra@latest` だけでも構いません。プロジェクト名・プロバイダ・API キーを順に聞かれます。

生成されるのは「エージェントハーネス」と呼ばれる構成で、ワークスペースツール・メモリ・タスク管理・Web アクセス・スケジュール・ストレージ・観測機能が最初から入っています。

## 1-2. API キーを設定して起動（10分）

```bash
# .env に API キーを記入（.env.example を参照）
cat .env.example

npm run dev
```

## 1-3. Studio で遊ぶ（20分）

ブラウザで http://localhost:4111 を開きます（DevContainer のポートフォワードで自動的に開くはず）。

> **画面の見方は [reference/mastra-studio.md](../../reference/mastra-studio.md) にまとめてあります。**
> 左ナビの構成、Traces 画面の読み方、トレースの保存先まで、Studio 全般の正典です。

やってみること:

1. 左メニューからエージェントを選び、適当なメッセージを送る
2. **右サイドバーのトレース表示を見る** — どのツールが呼ばれ、何が返ったかが可視化される
3. ツールを持つエージェントに「今日のタスクを整理して」など、ツールを使わざるを得ない指示を出す
4. 生成された `src/mastra/` 以下のファイルをエディタで眺める

> **注目ポイント**: このトレース画面が「エージェントが自分でツールを選んでいる」ことを最も直感的に確認できる場所です。スクリーンショットを撮っておくと、後で振り返るときに役立ちます。

**チェックポイント**
- [ ] Studio でエージェントから応答が返る
- [ ] トレースでツール呼び出しが確認できる
- [ ] `src/mastra/` の構成をざっと把握した
