# 6. テンプレート実行時の注意点

| # | 注意点 | 症状・理由 | 対処 |
|---|---|---|---|
| 1 | **テンプレートは作者が所有している** | 依存関係・モデル・環境変数・ソースコードはテンプレート側の定義が優先される | `--llm` は効かない（2-3）。モデルは手で差し替える |
| 2 | **`.env.example` を先に読む** | 必要なキーが分からないまま起動すると原因不明のエラーで詰まる | 起動前に必ず開く |
| 3 | **README を読む** | テンプレート固有のセットアップ手順がある | 各リポジトリの README を確認 |
| 4 | **バージョン差がある** | テンプレートによって Mastra のバージョンが異なる | `package.json` を確認 |
| 5 | **プロジェクトごとにディレクトリを分ける** | 既存プロジェクトの中で実行すると**入れ子になる**（2-1） | 毎回同じ親ディレクトリ（例: `~/work/mastra-handson`）へ `cd` してから実行 |
| 6 | **モデル指定が古いことがある** | 作者がモデル ID を固定しており、世代交代に追随しない | `grep -rn "openai/" src/` で確認し、古ければ差し替える（4-0） |
| 7 | **dev サーバーを同時に動かさない** | 4111 が塞がっていると**エラーにならず 4112 で起動**し、「変更が反映されない」と誤解する | 起動ログの `│ Studio: http://localhost:____` を必ず読む（[troubleshooting/ §1](../troubleshooting/)） |
| 8 | **pnpm 専用記法が残っていることがある** | `package.json` の `catalog:` / `workspace:` が展開されず、`npm install` が `EUNSUPPORTEDPROTOCOL` で落ちる。**失敗するとディレクトリごと巻き戻る** | `--no-install` でクローンだけ行い、実バージョンに直してから `npm install`（実例は 4-1） |
